# 📘 Tarefa: Jogo da Forca em Python

## 🎯 Objetivo

Praticar manipulação de strings, estruturas de repetição, condicionais e entrada de dados do usuário construindo o jogo da Forca em Python.

## 📝 Tarefas

### 🛠️ Configurar o Estado Inicial do Jogo

#### Descrição
Prepare os elementos iniciais do jogo, incluindo a escolha da palavra secreta e as variáveis que controlam o progresso da partida.

#### Requisitos
O programa completo deve:

- Selecionar uma palavra aleatoriamente de uma lista predefinida.
- Inicializar uma estrutura para armazenar letras já adivinhadas.
- Inicializar contadores de tentativas incorretas e o limite máximo de erros.

### 🛠️ Implementar o Loop Principal da Forca

#### Descrição
Implemente a lógica principal para receber palpites de letras, atualizar o estado do jogo e exibir o resultado final ao jogador.

#### Requisitos
O programa completo deve:

- Mostrar o progresso da palavra (por exemplo: `_ _ _ _`) a cada rodada.
- Solicitar uma letra ao usuário e validar a entrada.
- Atualizar letras corretas e tentativas incorretas conforme o palpite.
- Encerrar o jogo com mensagem de vitória quando a palavra for completada.
- Encerrar o jogo com mensagem de derrota quando o limite de tentativas for atingido.
